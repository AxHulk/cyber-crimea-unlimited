# Расчёт 700 / 800 квестов по данным сервера PW 1.3.6

Загруженный файл — архив Perfect World (Angelica File Package v2, ~35 МБ). Внутри должны лежать данные заданий (tasks.data) и, возможно, ограничения по уровню/расе/полу/культивации. Всё считаем по фактическим данным, а не по гайдам.

## Шаги

1. **Распаковать архив** во временную папку и найти файлы заданий (tasks.data, task_npc и т. п.) и описания (тексты, названия).
2. **Разобрать каждое задание**: ID, название, минимальный/максимальный уровень, требования к классу/расе, полу, культивации (Рай / Ад / без), признак повторяемого/ежедневного, родительская цепочка (засчитываются ли подзадания), взаимоисключения (выбор одной ветки из нескольких).
3. **Исключить** задания из «Праздничные загадки», «Счёт Фонарей», «Скачки в Городе мечей», «Скачки в Городе перьев», «Воинское Звание 7» (по названию и по их цепочкам).
4. **Посчитать для каждой комбинации**: раса (люди / сиды / зооморфы, а также по классам) x пол (м / ж) x путь (Рай / Ад) — накопительное число доступных засчитываемых заданий по уровням 1–105 и определить уровень, на котором набирается 700 и 800. Проверить заявление «800 на 93».
5. **Показать результат вам**: таблица уровней + список спорных случаев (что сервер считает «засчитываемым» — повторы, подзадания). Если правило счётчика неоднозначно, дам оба варианта.
6. **Обновить статью** в Медиа-хабе: заменить общие рассуждения на фактическую таблицу и вывод, с оговоркой «по данным файлов сервера».

## Риски

- Если в архиве нет tasks.data (только клиентские модели/интерфейс), сообщу и попрошу файл заданий отдельно.
- Формат tasks.data зависит от версии сборки; при расхождении придётся подобрать разбор под вашу версию.

## Технически

Распаковка PCK v2 (zlib, XOR-ключи 0xA8937462 / 0xF00EBEEF) скриптом Python в /tmp; разбор tasks.data по структуре ATaskTempl для 1.3.6; данные статьи — в существующем `perfectWorldArticle.ts`.
