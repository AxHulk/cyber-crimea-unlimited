

## Найденная проблема

В боковой панели "Другие материалы" на страницах статей (`Article.tsx`, строка 138) ссылки на галереи формируются как `/media-hub/gallery-dota2-cyberleague-2024` вместо `/media-hub/gallery/dota2-cyberleague-2024`. Из-за этого при клике на галерею из сайдбара открывается пустая текстовая страница Article, а не фотогалерея с масонри-сеткой.

Все остальное работает корректно: фильтры, обе галереи в разделе Галереи, интервью, итоги турниров, VOD-архив.

## План исправления

**Файл: `src/pages/Article.tsx`**

Использовать ту же логику `getItemLink` из `MediaHub.tsx` для формирования ссылок в сайдбаре. Если `item.id` начинается с `gallery-`, ссылка должна вести на `/media-hub/gallery/{id без префикса gallery-}`.

Строка 138: заменить `` to={`/media-hub/${item.id}`} `` на логику с проверкой `item.id.startsWith("gallery-")`, чтобы галерейные карточки вели на правильный маршрут `/media-hub/gallery/:galleryId`.
