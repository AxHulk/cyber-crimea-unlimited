

# ФКС РК — Cyber-Crimea Portal

## Этап 1: Дизайн-система и Главная страница

### 1. Фундамент дизайн-системы
- Обновить CSS-переменные: Deep Obsidian фон, Electric Purple, Acid Green, Cyber Blue
- Подключить шрифты: Oxanium (заголовки), JetBrains Mono (HUD/данные), Geist (текст)
- Компоненты в стиле «Tactile Maximalism»: механические кнопки с 4px тенями, HUD-оверлеи с corner brackets, глитч-эффекты
- border-radius: 2px, sharp shadows, RGB glow effects

### 2. Навигация
- Верхняя панель в стиле HUD с логотипом ФКС РК (загруженное изображение)
- Ссылки: Главная, Турниры, Новости, О Федерации
- HUD-индикаторы: «SYSTEM_STATUS: ONLINE», «ACTIVE_PLAYERS: 12,402»
- Мобильное меню с глитч-анимацией

### 3. Hero-секция с 3D-сценой (React Three Fiber)
- Полигональный wireframe горы Ай-Петри с неоновыми контурами
- Реакция на скролл: поворот камеры, переход гора → береговая линия
- Голографический текст: «CRIMEA_DIGITAL_FRONTIER»
- Scanline-анимация при загрузке

### 4. Bento Grid секция
- 12-колоночная сетка с модулями:
  - **Большой блок (6×4):** Текущий/ближайший турнир с обратным отсчётом
  - **Средний блок (3×4):** Турнирная сетка (превью)
  - **Малые блоки (3×2):** Региональные рейтинги, статистика
- Микроанимации: power-up при hover, подсветка границ, glitch-переходы

### 5. Новостная секция (асимметричная сетка)
- Карточки новостей с перекрытием изображений на -2rem
- Выделение главного события нестандартным размером блока
- Моковые данные для новостей

### 6. Footer
- Контакты ФКС РК, соцсети, спонсоры
- HUD-стилистика

## Этап 2: Дополнительные страницы

### 7. Страница «Турниры»
- Список турниров с фильтрами (дисциплина, статус)
- Карточки турниров в Bento-стиле
- Расписание матчей, турнирные сетки

### 8. Страница «Новости»
- Лента с асимметричной сеткой
- Страница отдельной новости

### 9. Страница «О Федерации»
- Информация о ФКС РК, руководство, контакты
- Документы, регламенты

## Этап 3: Backend (Lovable Cloud / Supabase)

### 10. База данных
- Таблицы: tournaments, news, players, matches, user_roles
- RLS-политики, профили игроков
- Авторизация (email + пароль)
- Админ-панель для управления турнирами и новостями
