

# Раздел «Арена» — план реализации

## Концепция
Полноценная страница `/arena` — центральный хаб киберспортивной активности ФКС РК. Использует все 11 загруженных неоновых иконок (10 из прошлого сообщения + icon_register). Bento-grid с HUD-стилистикой.

## Файлы

1. **`src/assets/arena/icon_register.png`** — сохранить загруженную иконку
2. **`src/pages/Arena.tsx`** — новая страница с Bento-секциями:
   - Hero-баннер с HUD-текстом
   - **Дисциплины** — 4 карточки (CS2, Dota 2, Valorant, FIFA) с неоновыми иконками, счетчиком активных игроков
   - **LIVE** — блок текущих трансляций с пульсирующим индикатором
   - **Турнирная сетка** — превью активного bracket
   - **Статистика** — ключевые цифры региона
   - **Прогнозы** — голосования/предикты на матчи
   - **Карта площадок** — список киберспортивных точек Крыма
   - **Зал славы** — топ-игроки с аватарами и достижениями
   - **Регистрация** — CTA-блок с иконкой icon_register
3. **`src/App.tsx`** — добавить роут `/arena`
4. **`src/components/HudNavbar.tsx`** — добавить «АРЕНА» в навигацию

## Стиль
- Все иконки импортируются из `@/assets/arena/` как ES-модули
- Каждая карточка — `bento-card hud-corner` с hover-эффектами
- Micro-animations через framer-motion (stagger, hover scale)
- Неоновые свечения соответствуют типу контента (зеленый — live, пурпурный — bracket, cyan — stats)
