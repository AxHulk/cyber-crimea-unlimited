

## Диагностика

Баг найден на строке 123 в `MediaHub.tsx`:

```tsx
<motion.div initial="hidden" whileInView="show" viewport={{ once: true, amount: 0.1 }}>
```

**`once: true`** — анимация срабатывает один раз при первом появлении контейнера во вьюпорте. После этого framer-motion считает анимацию завершённой и больше не запускает её. Когда пользователь переключает фильтр, контейнер уже во вьюпорте, `once: true` уже сработал — новые дочерние элементы получают `initial="hidden"` (opacity: 0, y: 18) и **никогда не анимируются в видимое состояние**. Поэтому карточки исчезают при смене фильтра.

## План исправления

**Файл: `src/pages/MediaHub.tsx`, строка 123**

Добавить `key={active}` на `motion.div`, чтобы при смене фильтра контейнер пересоздавался и анимация запускалась заново:

```tsx
<motion.div key={active} initial="hidden" whileInView="show" viewport={{ once: true, amount: 0.1 }} className="grid grid-cols-12 gap-4">
```

Одно изменение — одна строка. Это полностью решает проблему с пропаданием карточек при переключении фильтров.
